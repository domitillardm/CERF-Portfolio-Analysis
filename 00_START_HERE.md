# CERF portfolio analysis — start here

CERF is the Climate and Energy Response Facility. Its End-Term Evaluation portfolio
analysis examines reported results and evidence across tracks, supported by
activities organised by country, track and chronology. Findings remain provisional.

Read `AGENTS.md`, `handover.json` and `01_METHODOLOGY/PROJECT_EXPLAINED.md` first.
The handbook distinguishes owner-provided context, external completion claims,
missing records and proposed methods. Data preparation/anonymisation are reported
complete outside this repository; supporting files are not linked. The immediate
priority is reviewing existing grading instructions against the Inception Report
and preparing country-track analysis. No approved scoring framework is supplied.
Preserve existing scores. The highest-human-checked-score proposal is unapproved.

The latest versioned status, internal history and client draft are in the directory named by handover.json.latest_report. If absent, no session has been finalized with the current workflow.

See ENVIRONMENT.md for setup, session commands and persistence checks.

See `05_VALIDATION/issues.md` for blockers and
`09_INTERNAL_DEEP_DIVE/technical_and_decision_history.md` for the internal guide.
New documentation awaits review; no grading, dataset upload or client publication
is authorised by this documentation update. Commit and push require approval.
